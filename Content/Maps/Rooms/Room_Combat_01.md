# Room_Combat_01 — 正式战斗房模板规格

| 字段 | 内容 |
|------|------|
| Type / Tag | Combat / Early |
| Owner | 廊道 |
| 状态 | **规格定稿候选** · COMMENT 交审 · 待 UE umap |
| 尺寸 | 设计宽 **1280**（2 屏）· 640×360 正交 |
| 意图 | 开局压枪、左右走位、矮台风筝、2D 站位 Peek |
| 入口安全区 | 入口内侧 X≈0–320，无伤害体积、无刷怪点 |
| Spawn | Ground×4；W1:2 / W2:2；无 Air/Elite |
| 同时存活上限 | ≤4 |
| Exit | Left 入口 · Right 前进 `RequireClear` |
| 清房 | 波次清空 → 三选一 → 开门（GDD） |
| 数据 | `Content/Data/Rooms/Room_Combat_01_*.csv` |
| 禁止 | 坑杀、单级 ≥32 必过台、进房贴脸刷怪、跳上掩体顶 Peek、fake uasset |

**坐标：** 原点 = 左侧入口内侧地面（玩家脚底参考）；`+X` 向右出口；`+Y` 向上；1 设计 px = 1 uu（与 Lab 程序化一致）。

**手感锚点（布局侧，不改 JumpZ）：** 现行净跳 ≈32 → 台阶级差 ≤**28**；掩体 Peek = **穿过后站对侧（沿 X）**，非跳顶、非绕 Y。

## 6. 数据表（无 uasset）

| 文件 | 用途 |
|------|------|
| `Content/Data/Rooms/Room_Combat_01_meta.csv` | 房间元数据 / 标签 / 清房规则 |
| `Content/Data/Rooms/Room_Combat_01_spawns.csv` | 刷怪点机读表 |
| `Content/Data/Rooms/Room_Combat_01_geometry.csv` | 几何/出口机读表 |

列约定：`Floor` 用 `x0`–`x1`，`top_y` 为行走面。`Wall` 的 `top_y` 是墙顶 Y（自地面高 280），`height` 留空。`Platform` / `Cover` 用 `x_center`+`width`；平台 `top_y` 为行走面，掩体 `top_y` 为底面 Y、`height` 为竖向尺寸。点位（Anchor / Exit）`x0`=X、`x1`=Y。

敌 ID 用占位 `Enemy.Grunt.Early`（数值归词条官 / 弹芯）；本规格只定几何与波次槽位。
