# Room_Combat_04 — 正式战斗房模板规格

| 字段 | 内容 |
|------|------|
| Type / Tag | Combat / Mid |
| Owner | 廊道 |
| 状态 | **规格定稿候选** · COMMENT 交审 · 待 UE umap |
| 尺寸 | 设计宽 **1760**（约 2.75 屏）· **坑 + 桥** |
| 意图 | 空间风险与桥上走位/对射；可读坑，非暗坑 |
| 入口安全区 | 左侧平层 X≈0–280；坑不挡出生 |
| Spawn | Ground×4（桥两端/坑缘）；可选 Air×1 @W2 |
| 同时存活上限 | ≤6 |
| Exit | Left / Right · Right **`RequireClear`** |
| 清房 | 波次清空 → **三选一** → 开门 |
| 数据 | `Content/Data/Rooms/Room_Combat_04_*.csv` |
| 禁止 | 一落即死且无预警的暗坑、单级 ≥32 必过、进房 Air 贴脸、fake uasset、改 Lab 跳跃/级差 |

**坐标：** 原点 = 左侧入口内侧地面；`+X` 右；`+Y` 上；1 px = 1 uu。  
**手感：** 级差 ≤28；桥面 TopY=**28**；落坑 = **软回收**至桥左安全点（轻伤可配，默认 0，与 Lab 软回收精神一致，正式房可后调伤）。Peek = 沿 X 站掩体对侧。

## 1. ASCII 侧视（约 1 字符 ≈ 40 px）

```
Y
28|              [====桥====]
 0|==安全==近场====坑空====远场========出口=
   +------------------------------------→ X
     0   280  560  720  960  1280   1760
```

坑区 X 720–960 **无地板**；桥板同跨度 TopY=28 常驻可走；坑缘/桥两端刷怪。
