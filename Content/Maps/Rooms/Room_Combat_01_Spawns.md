# Room_Combat_01 — 刷怪点坐标表（相对入口）

**坐标系**
- 原点：左侧入口内侧地面 = `(0, 0)`（玩家脚底参考）。PlayerStart 在 `(40, 0)`，不是原点
- `+X`：朝右出口（前进方向）；`+Y`：向上
- 单位：逻辑像素（参考分辨率 640×360）；1 设计 px = 1 uu；房间设计宽 **1280**（2 屏）
- 右出口中心约：`(1200, 0)`（门洞另计碰撞）

**同时存活上限：** ≤4  
**波次：** W1 → 清完或超时 → W2

## 给弹芯 P0 沙盒

- 无 Air / Elite 点；全 Ground。
- 首波（G1/G2）进房 **0.5–1.0s** 激活；出生时若相机跟玩家，点位应在屏外或半遮挡（相对入口 ≥420）。
- 可先用空 Actor + 标签套表；正式挂 `BP_SpawnPoint` 后按同坐标摆。
- 数值敌 ID / 血量不在本表；只定几何。
