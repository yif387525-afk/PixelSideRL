| 字段 | 内容 |
|------|------|
| Type / Tag | Elite / Mid |
| Owner | 廊道 |
| 状态 | **骨架规格定稿候选** · **尚无 umap** · 建图清单 `Docs/Room_Elite_02_UMapBuild.md` |
| 尺寸 | 设计宽 **1920**（3 屏）· **高台压制** |
| 意图 | 精英站 **TopY=28 高台** 俯射/压迫；地面侧廊夹击；与 `Elite_01` 中央地坪竞技场形成轮换差异 |

| Exit | Left / Right · Right **`RequireClear`** |

| 数据 | `Content/Data/Rooms/Room_Elite_02_*.csv` |
| 禁止 | 多精英、精英与出口门重叠、进房精英贴脸、暗坑、单级 ≥32 必过、fake uasset、改 Lab 跳跃/级差、直连 Boss、照搬 Elite_01 中央地坪布局 |

**坐标：** 原点 = 左侧入口内侧地面；`+X` 右；`+Y` 上；1 px = 1 uu。  
**手感：** 级差 ≤28（高台 TopY=28，可单跳上台）；Peek = 沿 X 站掩体对侧。波次：W1 杂兵铺场 → W2 精英登场（`Spawn.Elite`，站在高台上）。

## 7. 与 Elite_01 轮换差异

| | Elite_01 | Elite_02 |
|--|----------|----------|
| 主题 | 中央地坪竞技场 | 高台压制 |
| 精英站位 | 地面 (1100, 0) | **台上 (1080, 28)** |
| 平台 | 两侧短台 | 中央精英台 + 左右接近台 |
| 压迫读法 | 开阔对峙 | 仰角 + 侧廊夹击 |

同一次 Run 仍只抽 **1** 个 Elite（见 RoomPipeline §6.1）；二者进池轮换。

## 8. 入库验收

- [ ] 精英唯一且站高台 TopY=28；非贴脸、不压出口  
- [ ] 级差 ≤28；无暗坑；侧廊可读冲锋  
- [ ] W1 杂兵 → W2 精英；同时 ≤8  
- [ ] RequireClear + 三选一；CSV 齐；无 Lab 改动；布局不照搬 Elite_01
