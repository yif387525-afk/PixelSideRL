## 0. 设计目标

| 要 | 不要 |
|----|------|
| 落差平台、短掩体、可跳路线 | 一条平地灰盒 |
| 木桩 / 炮塔合理站位，可练 Peek | 炮塔贴脸秒杀 |
| 服务 Checklist：Coyote、Buffer、仰角射击 | 正式波次 / 三选一 / 清房锁 |
| 正交 640×360，跟 X | 超出跳跃能力的必过坑 |

**手感锚点（CombatFeel）**

| 参数 | 值 | 布局含义 |
|------|-----|----------|
| 角色高 | ~40 px | 一级台阶 ≤36 px 可单跳上台 |
| JumpZ / Gravity | 420 / ×2.2 | 舒适净跳高按 **~48–56 px** 设计（含 Coyote） |
| MaxWalkSpeed | 220 | 单屏穿越 ~2.9 s |
| 炮塔 / 玩家伤害 | LabSetup 现状 | 炮塔须有掩体遮挡线；开火间隔可读 |

|------|--------|
