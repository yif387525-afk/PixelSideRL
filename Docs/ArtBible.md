# ArtBible — PixelSideRL 像素美术规范

**维护：** 点阵（像素美术）  
**对齐：** `UE_PROJECT_SPEC.md`  
**状态：** **v1.1**（色板/12fps/640×360/Nearest/`T_` 仍锁定；**玩家规格以 v3 为准**：帧约 32×40、身高约 32px、小头结实躯干、贴身短枪）

---

## 1. 目标观感

侧视横版射击 Roguelike。清晰可读优先于细节堆砌：角色剪影一眼可辨，弹道与受击反馈醒目，房间模块可拼而不糊。

- 逻辑分辨率：**640×360**
- 显示：整数倍最近邻放大（2× / 3× / 4×）
- 相机：正交，水平滚动为主

---

## 2. 像素密度（强制）

| 对象 | 高度（像素） | 备注 |
|------|-------------|------|
| 玩家角色 | **约 32 px**（帧 **32×40**，亦可记约 36×36 量级） | **v3 锁定**：头约 6px、躯干结实、斗篷剪影、四肢利落；贴身短枪；脚底对齐 |
| 常规敌人 | 24–40 px | 小型偏矮，人形对齐玩家 |
| 精英 / 大型敌 | 48–64 px | 不超过一屏高度 1/3 |
| Boss | 80–120 px | 分部位绘制，可多段碰撞 |
| 武器（手持） | 玩家默认**贴身短枪**约 4–6 px 长（长枪另案） | 枪口高亮 1 px；Fire tip 行固定 |
| 子弹 / 投射物 | 2–8 px | 主弹道色高对比 |
| 地砖 | **16×16** 为主 | 可拼 32×16 平台条 |
| UI 图标 | 16×16 / 24×24 | 三选一卡面另见 §7 |

**透视：** 严格侧视，无 3/4 转面；厚度用 1–2 px 暗边暗示即可。

**玩家 v3（已过目）：** 死亡细胞式紧凑比例（勿抄原作角色）——头小、躯干厚、剪影可读；武器为**贴身短枪/手枪 trunc**，Fire 枪口水平且 tip 行固定供挂弹点。

## 3. 色板

### 3.1 主色板（**v1.0 锁定**）

**32 色**「冷工业 + 暖强调」：暗底可读、弹道暖色跳出。色值放入 `Content/Art/Palettes/T_Palette_Master.png`（1×32 或 8×4 swatch）。

| 用途 | Hex | 说明 |
|------|-----|------|
| 背景最深 | `#0D1118` | 远景空洞 |
| 地面暗 | `#1A2332` | 地砖暗部 |
| 地面中 | `#2E3D52` | 主地面 |
| 地面亮 | `#4A6280` | 高光边缘 |
| 墙体 | `#3A4555` / `#5C6B7A` | 室内模块 |
| 金属暗/亮 | `#2A2E35` / `#8B93A0` | 枪械、机械敌 |
| 皮肤暗/亮 | `#8B5A3C` / `#C48A64` | 玩家 |
| 服装主色 | `#3D6B8C` | 玩家识别色（可随解锁换皮） |
| 敌方警告 | `#C43C3C` | 攻击预警、血条敌方 |
| 友方/拾取 | `#3CC48A` | 治疗、可交互 |
| 弹道主色 | `#F0C040` | 玩家子弹 |
| 弹道敌色 | `#E060A0` | 敌弹区分 |
| 受击闪白 | `#F5F0E8` | 1–2 帧 hit flash |
| UI 文字 | `#E8EEF5` | 正文 |
| UI 描边 | `#0D1118` | 1 px 外描边 |

规则：

1. **禁止**在正式资源里引入主色板外颜色（调试可用 `_Dev`）。
2. 渐变最多 **3 阶**（暗 / 中 / 亮）；禁止平滑抗锯齿渐变。
3. 稀有词条色：普通灰白 · 稀有蓝 `#5B8DEF` · 史诗紫 `#A86BFF` · 传说金 `#F0C040`（与弹道金共用需靠形状区分）。

### 3.2 导入

- `Content/Art/Palettes/` 仅放色板与参考条。
- UE 贴图：**Nearest**，无 mip 模糊；sRGB 视情况，UI 开 sRGB，世界精灵按项目约定统一。

## 4. 动画帧率与帧数

全局动画时钟建议 **12 fps** 表现层（逻辑可 60）。循环动作用偶数帧，便于乒乓。

| 动作 | 帧数（参考） | 备注 |
|------|-------------|------|
| Idle | 4 | 呼吸/重心微晃 |
| Run / Walk | 6–8 | 接触帧清晰 |
| Jump / Fall | 4–5 | rise 屈腿蓄力、apex 收腿/枪微抬、fall 伸腿落地；腿与手臂须可读 |
| Fire（上半身） | 2–3 | 后坐 1 帧 + 复原 |
| Hit / Hurt | 2 | 闪白可叠材质 |
| Death | 4–6 | 最后一帧可持有 |
| 敌人 Attack 预警 | 2–4 | 必须可读，服务打手感 |
| FX（枪火/爆炸） | 3–5 | 不循环；粒子用短帧 |

- 同角色 **统一 pivot**（脚底中心）；翻转仅水平镜像，不单独画左向。
- 开火与移动分层：下半身走/跳，上半身瞄准（若首版合一体，pivot 仍按脚底）。

## 5. 技术规格

| 项 | 约定 |
|----|------|
| 格式 | PNG，透明背景；禁止 JPG |
| 导出 | 整数缩放，无半像素 |
| 命名 | `T_` + 主体 + `_` + 状态，PascalCase 主体。例：`T_Player_Idle`、`T_EnemyDrone_Run`、`T_Wpn_Peashooter`、`T_Fx_Muzzle_01` |
| 精灵表 | 可选；单帧文件优先 MVP。若打包：行优先、帧尺寸固定、留 0 px 间隙或 1 px 透明 |
| 碰撞 | 显示与碰撞可差 1–2 px，偏移记入 `Docs/CombatFeel.md`，美术不擅自改碰撞盒 |
| 材质 | 默认 `MI_PixelSprite_Unlit`（Nearest + Unlit） |

## 6. 目录与提交

```
Content/Art/
├── Characters/     # 玩家与可玩皮肤
├── Enemies/        # 按敌人 ID 分子文件夹，如 EnemyDrone/
├── Weapons/        # 枪体、弹着、弹道精灵
├── FX/             # 枪火、爆炸、受击、提示箭头
├── Environments/   # 地砖、道具、门、背景层（Far/Mid/Near）
├── UI/             # HUD、三选一卡、图标
└── Palettes/       # 主色板与主题变体
```

- 临时稿只进 `Content/_Dev/`，合入前经本规范自检。
- 大文件走 Git LFS（`png` / `uasset`）。
- PR：美术改动 + `Docs/ArtBible.md` 若规则有变更则同行更新一行说明。

## 7. 分类细则（摘要）

**角色 / 敌人：** 剪影测试——缩到 25% 仍可辨；敌方攻击色偏暖红/粉，玩家识别偏蓝青。  
**武器：** 枪口必须有 1 px 高亮；换枪时枪体色不与敌弹混淆。  
**环境：** 16×16 网格；出口/门用高对比描边；危险地面用敌方警告色条纹。  
**FX：** 短、亮、少帧；屏幕空间 UI FX 与世界 FX 分目录。  
**UI：** 字号按像素字体整数倍；卡面边框 1–2 px；禁用半透明模糊叠层。对接 `Docs/UI_Wireframes_P0.md`：
  - 词条图标格 **12×12**（间距 2，HUD 最多 8）
  - 武器图标 **16×16**
  - AffixCard **120×168**；稀有度色边跟本色板
  - 不改角色 40px 比例

## 8. MVP 产出清单（美术）

对应工程 MVP：1 角色 · 3 枪 · 3–5 敌 + 1 Boss · 基础地砖与门 · 必要 FX/UI。

1. `T_Palette_Master` + 本文件锁定  
2. 玩家：Idle / Run / Jump / Fire / Hurt  
3. 枪 ×3：枪体 + 枪火 + 弹道  
4. 敌人各：Idle / Move / Attack / Hurt / Death（可先共用 Hurt）  
5. Boss：至少 Idle + 两阶段攻击可读动画  
6. 环境：地砖套件、门/出口、1 套近景装饰  
7. UI：血条、武器图标、三选一卡框、稀有度色条

## 9. 变更流程

1. 点阵改草案 → 同步 `@小yan`  
2. 色板 / 密度 / 帧率属**硬锁定**项，改动需主管确认后再升版本号  
3. 版本记在本文件文首；重大变更通知战斗（弹芯）、关卡（廊道）以免碰撞与房间尺度漂移
